# Momias de Guanajuato: La Leyenda

Plataformas con fisica real construido con TDD (Flutter / Dart).

## Como ponerlo a funcionar (VS Code)
1. flutter create momias_guanajuato
2. Copia lib/, test/ y pubspec.yaml de este zip dentro de esa carpeta (reemplazando).
3. Borra test/widget_test.dart
4. flutter pub get
5. flutter test
6. flutter run   (o F5 en VS Code)

Teclado en escritorio/web: flechas o A/D para moverte, espacio/W/flecha arriba para saltar.
